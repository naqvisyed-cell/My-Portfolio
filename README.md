# 💜 My Portfolio

Personal portfolio website of **Syeda Farwa Naqvi**, a Software Engineering student with a passion for UI/UX design.

🔗 **Live site:** https://YOUR-USERNAME.github.io/My-Portfolio/

## ✨ Features

- Clean, light pastel design (pink, lavender and mint)
- 3D look with tilting cards, raised buttons and spinning cubes
- Smooth scroll animations and hover effects
- Fully responsive for mobile, tablet and desktop
- Respects reduced-motion settings for accessibility
- Single-file website, with no frameworks or build step

## 🛠️ Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, 3D transforms, keyframe animations)
- Vanilla JavaScript (scroll reveal and card tilt)
- Google Fonts: Fraunces, Figtree and JetBrains Mono

## 🚀 Run locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## 🌐 Deploy with GitHub Pages

1. Make sure `index.html` is in the main folder of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **main** branch and the **/ (root)** folder, then click **Save**.
5. Your site will be live after a minute or two.
